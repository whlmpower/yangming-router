# 阳明心学实践指南 Skill 系统

基于《传习录全集》与王阳明生平资料构建的阳明心学实践 Skill 系统，帮助用户在具体困境中运用心学智慧，输出可执行的日常功夫。

## 仓库结构

```
├── yangming-skills/          # Skill 系统
│   ├── yangming-router/      # 主入口：根据用户意图路由到对应 Skill
│   ├── yangming-core/        # 共享层：人设、模型、输出模板、安全规则、引用规范
│   ├── yangming-learning/    # 学习 Skill：系统学习阳明心学核心概念
│   ├── zhi-liangzhi/         # 致良知：迷茫、选择困难、内心挣扎
│   ├── zhixing-heyi/         # 知行合一：知道但做不到、拖延、执行力
│   ├── jingzuo-xingsheng/    # 静坐省察：内耗、思绪纷乱、需要定力
│   ├── siju-jiao/            # 四句教：道德困境、重大决策、良知判断
│   ├── mingxin-faxing/       # 立志与诚意：方向缺失、意义感缺失
│   └── shishang-molian/      # 事上磨练：具体困境、反复受挫
├── 传习录全集/               # 《传习录》原文资料（按卷、录分级）
└── 生平/                     # 王阳明生平资料
```

## Skill 框架

### 整体架构

```
yangming-router (主入口)
    ↓
yangming-core (共享层：人设、模型、模板、安全、引用)
    ↓
6 个实践 Skill + 1 个学习 Skill
```

### 共享层（yangming-core）

- **persona.md**：中度人设规则，第一人称阳明口吻 + 现代白话解释
- **models.md**：5 个核心思想模型 + 7 条处世启发式 + 价值观与反模式
- **output-template.md**：六段式输出骨架（阳明如是说 / 心学之法 / 今日功夫 / 日日不断 / 照见盲区 / 下一步）
- **safety.md**：危机识别与退出机制，心理援助热线
- **sources.md**：三级来源分级（可信层 / 解读层 / 演绎层）

### 实践 Skill（6 个）

每个 Skill 解决一类具体困境，输出遵循统一的六段式骨架：

| Skill | 解决什么 | 触发话术示例 |
|-------|----------|--------------|
| zhi-liangzhi | 迷茫、选择困难、内心挣扎 | 「我不知道自己要什么」「怕选错」 |
| zhixing-heyi | 知道但做不到、拖延、执行力 | 「我知道但就是做不到」「三分钟热度」 |
| jingzuo-xingsheng | 内耗、思绪纷乱、需要定力 | 「心静不下来」「停不下来地想」 |
| siju-jiao | 道德困境、重大决策、良知判断 | 「这事该不该做」「怎么判断对错」 |
| mingxin-faxing | 方向缺失、意义感缺失 | 「找不到人生方向」「活着像行尸走肉」 |
| shishang-molian | 具体困境、反复受挫 | 「这件事让我很痛苦」「过不去」 |

### 学习 Skill（1 个）

| Skill | 解决什么 |
|-------|----------|
| yangming-learning | 系统学习阳明心学核心概念、思想模型、处世启发式 |

## 使用方式

### 1. 安装

在 Agent 对话框中输入：

```
请帮我安装 `https://github.com/whlmpower/yangming-router` 中的 skill
```

### 2. 激活 Skill

直接对 AI 说触发话术，例如：

- 「我不知道自己要什么」 → 激活 `zhi-liangzhi`
- 「我知道但就是做不到」 → 激活 `zhixing-heyi`
- 「心静不下来」 → 激活 `jingzuo-xingsheng`
- 「这事该不该做」 → 激活 `siju-jiao`
- 「找不到人生方向」 → 激活 `mingxin-faxing`
- 「这件事让我很痛苦」 → 激活 `shishang-molian`

### 3. 工作流程

每个实践 Skill 遵循统一的工作流程：

1. **阳明式追问**（2-4 轮）：通过苏格拉底式反问挖掘用户真实处境
2. **六段式输出**：
   - 【阳明如是说】：阳明第一人称回应
   - 【心学之法】：方法论总结，自动分层（初学者白话 / 进阶者原文）
   - 【今日功夫】：针对当下困境的即时练习
   - 【日日不断】：每日固定功课
   - 【照见盲区】：2-3 个反问帮用户看见盲区
   - 【下一步】：建议式切换到其他 Skill

### 4. 输出特点

- **中度人设**：第一人称阳明口吻 + 现代白话解释
- **自动分层**：根据用户词汇和接受度自动调整深度
- **建议式切换**：不自动串联 Skill，由用户显式选择
- **危机降级**：识别危机信号时，跳过六段式，只提供共情和专业帮助引导

## 引用规范

所有引用遵循三级分级：

- **可信层**：传世经典原文，可直引
- **解读层**：注家解读，标注出处
- **演绎层**：Skill 为了教学便利做的现代转化，必须标注「据传」

特别规则：第 11 条「此心不动」在 Skill 中引用时，必须同时标注「据传」，不得省略。

## 危机处理

当用户处于以下状态时，Skill 会立即切换危机流程：

- 明确表达自杀倾向
- 描述自伤行为
- 处于急性创伤期（事件发生后的数小时到数天内）
- 严重抑郁信号（持续 2 周以上的情绪低落、对一切失去兴趣、睡眠饮食严重紊乱、自我评价极低）

## 内容分层

- **初学者层**：白话为主 + 生活化例子，不引用原文或少量引用
- **进阶者层**：原文引用 + 白话翻译 + 深度解读

Skill 会根据用户的提问方式和接受度自动判断分层。
